# Contributing

Thanks for helping improve Abracadabra Password Generator.

## Before You Start

- Check existing issues and pull requests so work is not duplicated.
- Keep changes focused and explain the user-facing impact.
- Do not add passwords, tokens, personal data, or generated build files.

## Local Testing

1. Load the repository as an unpacked extension from `chrome://extensions`.
2. Make your change.
3. Press **Reload** on the extension card.
4. Test generation, length changes, option combinations, copying, keyboard navigation, and narrow popup layouts.

## Pull Requests

Include a short summary, testing steps, and screenshots for visual changes. Keep the default branch passing its documented checks and be respectful in review.
